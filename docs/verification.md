# 实现选择与验收

验收日期：2026-10-04。

## 需求中需要取舍的地方

1. **容器启动后打开宿主网页**：Linux 容器不能直接操作 macOS 图形会话。提供当前用户 LaunchAgent 浏览器助手，由一键启动器安装；根据健康接口的实例编号，每次容器启动打开一次前端。服务随容器启停，助手仅检查本机健康接口，可独立卸载。
2. **安装 skill 后每项任务都通知**：仅复制 SKILL.md 不能强制所有 Agent 自动选用。导出包附显式安装器，同时安装 skill 与受管理的 Codex AGENTS.md / Claude CLAUDE.md 通知规则，保留现有配置，支持卸载。没有在开发时擅自安装到当前 Agent。
3. **等待接口和超时**：创建请求立即返回持久 ID，后续使用最长 25 秒的长轮询持续等待，避免单次 HTTP 长连接跨越全部等待期。回复默认期限 5 分钟，API 支持 30 秒到 24 小时。按邮箱服务器接收时间判断及时回复；截止后最多 30 秒核对最后一批邮件。超时不等于同意，Agent 按原有权限与风险决定继续或暂停。
4. **轻量依赖与凭据**：Python 标准库 + SQLite + 原生前端，无 pip/npm 运行依赖。SMTP/IMAP 必须使用 TLS，使用邮箱服务商的授权码或应用专用密码；不提供 OAuth 流程。凭据保存在权限受限的本机数据卷，不声称静态加密。
5. **异常重启与重复邮件**：HTTP 使用幂等键。SMTP 没有可用的端到端 exactly-once 协议，发送中崩溃后将结果标为未知并保存可读解释，不盲目重复发送。诊断记录原子写入终态，不会作为邮件发送。
6. **历史收件边界**：完整历史记录长期保存；后台自动收取回复覆盖最近 30 天最多 300 个对话，始终优先最多 100 个活跃请求。晚到回复单独标记，已超时的请求不会被重新激活。自动回复、非目标发件人和无关联邮件不会作为用户决策。

## 已执行验证

- Python 自动化测试：**62 项通过**，覆盖参数校验、CSRF/同源/Host/API 权限、幂等性、配置和回复持久化、重启恢复、时间边界、邮件解析、安装器及浏览器助手。
- 本机 TLS SMTP/IMAP 回环：真实 socket、真实 Python SMTP/IMAP 客户端，验证 CLI → HTTP → SMTP → IMAP → API → CLI 复述中文回复，以及非目标发件人过滤、发信和收件失败。
- 前端请求重试行为：丢失响应、刷新恢复、相同键与正文重试、明确拒绝后清理、配置变更后避免发往新地址；语法检查通过。
- 浏览器实际操作：配置保存、SMTP/IMAP 检查、对话测试回复、记录筛选、错误解释、详情时间线和深浅色切换；控制台无异常。320、390、768、1024、1440 像素宽度没有横向溢出。
- Docker：构建成功、非 root、只读根文件系统、只发布宿主 `127.0.0.1:10086`。独立无外网测试容器验证配置、令牌、失败记录在重启及删除重建容器后保留；测试资源自动清理。
- 导出 ZIP 通过真实 HTTP 下载并在隔离目录安装，未修改实际 Agent 全局规则。
